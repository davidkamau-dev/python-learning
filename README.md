## Projects

### Simple Calculator

A beginner Python calculator that accepts two numbers and performs:

- Addition
- Subtraction
- Multiplication
- Division

I built and tested this project while learning Python fundamentals.
### Number Guessing Game

A beginner Python game that generates a random number between 1 and 10 and asks the player to guess it.

The program compares the player's guess with the secret number and tells the player whether the guess is correct, too high, or too low.

I built and tested this project while learning Python fundamentals, conditional statements, and the random module.
